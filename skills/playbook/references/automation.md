# 자동화·배치·규칙 판정

## 최소 구조
- CLI 한 개: `입력 경로 → 처리 → 출력 경로`, 옵션은 꼭 필요한 것만.
- 규칙은 코드에 흩지 말고 표(딕셔너리/JSON/CSV)로: 규칙 ID · 조건 · 기준값 · 경계 포함 여부 · 우선순위 · 결과. 담당자 답이 바뀌면 표만 고친다.
- 판정 결과에는 근거를 같이: 어떤 규칙 ID 때문에 어떤 판정인지.

## 순서
1. 규칙 표를 담당자 답·지시서에서 만든다(경계값 "이상/초과" 를 꼭 확인)
2. 판정 함수 + 규칙별 테스트(경계값 바로 위·아래·같음)
3. 파일 입출력, 오류 행 처리(건너뛰고 따로 기록)
4. 실행 요약: 처리 건수·판정별 건수·오류 건수 출력

## 검증
- 규칙마다 최소 3개 경계 테스트
- 실행 요약 숫자의 합이 입력 건수와 같은지
- 0건 처리로 "위반 0건" 이 나오는 경우를 막기(처리 건수 0이면 실패로)

## 함정
- 규칙 충돌 시 우선순위 미정 → 담당자 질문
- 예외 규칙(특정 대상 제외)을 일반 규칙 뒤에 적용
- 단위·시간대 섞임
