# API·백엔드

## 최소 구조
- 엔드포인트 목록을 먼저 표로: 메서드 · 경로 · 입력 · 출력 · 오류 · 요구 ID.
- 계층은 두 개면 충분: 라우트(입출력 검증) → 로직 함수(순수 함수로, 테스트 대상).
- 저장소: 메모리/JSON/SQLite 순으로 단순한 것부터. 동시성·캐시·큐는 요구에 있을 때만.

## 순서
1. 헬스체크 + 핵심 엔드포인트 하나가 끝까지 도는 판
2. 로직 함수 단위 테스트
3. 나머지 엔드포인트, 오류 응답 형식 통일(상태 코드 + 메시지)
4. README 에 `curl` 예시

## 검증
- 엔드포인트마다 정상 1개 + 오류 1개 `curl` 결과를 남긴다.
- 로직 테스트는 경계값(빈 목록, 최대값, 잘못된 형식) 포함.

## 함정
- 0.0.0.0 바인딩 누락, 포트 하드코딩
- 입력 검증 없이 예외가 500 으로 새어 나감
- 시간대 없는 datetime 비교
- 요구에 없는 인증·권한·페이지네이션을 넣느라 시간 소모
