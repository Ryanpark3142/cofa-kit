# 데이터 분석·리포트

## 최소 구조
- `analysis.py`(또는 `.mjs`) 한 파일 또는 단계별 스크립트: 읽기 → 정제 → 집계/모델 → 결과 파일(CSV/MD/PNG).
- 결과 보고서 `REPORT.md`: 질문 → 방법 → 결과(표·수치) → 해석 → 한계 → 제안.
- 노트북보다 스크립트: 다시 돌려 같은 결과가 나오는 것이 증거다. 난수는 시드 고정.

## 순서
1. `$data-first-look` → 결측·이상값 의미를 담당자에게 확인
2. 업무 질문을 분석 질문으로 바꾼다("수율이 왜 떨어졌나" → "기간·설비·로트별 수율 차이와 그 크기")
3. 가장 단순한 집계(그룹별 평균·건수·비율)부터. 복잡한 모델은 단순 집계로 설명이 안 될 때만
4. 결과마다 "그래서 무엇을 하면 되나"를 한 줄로

## 검증
- 행 수 추적: 원본 → 필터 → 조인 후 행 수를 매 단계 출력(조인으로 행이 불어나거나 사라지는지)
- 핵심 숫자 1~2개는 다른 방법(작은 표본 손계산, 다른 코드 경로)으로 다시 계산
- 그룹 비교는 표본 수를 같이 보여준다. 작은 그룹의 극단값을 결론으로 쓰지 않는다
- 상관을 원인으로 쓰지 않는다. 원인 주장은 "가설"로, 확인 방법과 함께

## 함정
- 결측을 0으로 채워 평균 왜곡
- 중복 행, 조인 키 형식 차이(앞자리 0, 공백)
- 시간대·날짜 형식 섞임, 단위 섞임(%, ppm, 개수)
- 그래프만 있고 수치·해석이 없는 보고서
- 엑셀 날짜 일련번호(45000 같은 숫자)
