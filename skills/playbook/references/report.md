# 문서 산출물 (기획서·설계서·분석 보고서)

## 구조 (지시서 양식이 있으면 그것이 우선)
1. 문제: 누가 어떤 상황에서 무엇 때문에 곤란한가(담당자 답 인용)
2. 목표와 성공 기준(숫자)
3. 현황·근거: 제공 데이터·자료의 수치, 출처 위치
4. 해결안: 선택안과 버린 대안, 이유
5. 실행 계획·검증 방법
6. 위험·한계·다음 단계

## 원칙
- 주장마다 근거 위치(파일·행·담당자 답)를 붙인다. 근거 없는 수치는 쓰지 않는다.
- 추론은 "가설"로 표시하고 확인 방법을 붙인다.
- 짧게. 표와 수치가 문장보다 낫다.
- 사용자가 사후에 설명해야 하므로 사용자가 동의한 판단만 넣는다.

## 검증
- 문서의 숫자를 원자료에서 다시 계산해 대조
- 지시서 요구 항목이 모두 문서에 있는지 체크리스트로
