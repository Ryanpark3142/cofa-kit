# handoff — 세션 교체

긴 대화는 느리고 비싸며 앞의 결정을 잊는다. 압축을 반복하기보다 상태를 파일에 남기고 새 세션으로 넘어간다. 다른 탭의 작업 세션은 그대로 둔다(그 탭의 상태는 `.cofa/tasks/` 에 있다).

## 언제
- 단계가 바뀔 때(파악→구현, 구현→검증), 또는 약 90분 시점
- 같은 오류를 두 번 고쳤는데 또 날 때
- 응답이 눈에 띄게 느려지거나 이미 정한 것을 다시 묻기 시작할 때

## 순서
1. `WORKLOG.md` 맨 위(제목 바로 아래)의 `## 현재 상태` 를 **덮어쓴다**(없으면 만든다). 5줄:
   ```
   ## 현재 상태 (<시각> · 경과 N분)
   - 완료: R1, R2 (검증됨) / R3 구현됨·미검증
   - 진행 중: <무엇> — <어느 파일> 까지 / 다른 탭: T2(진행)
   - 다음 할 일: <한 가지>
   - 주의: <함정·담당자 답 중 잊으면 안 되는 것>
   - 막힘: <없음 | 무엇>
   ```
2. 커밋: `node .cofa/kit/scripts/kit.mjs commit -m "chore: 세션 인계 상태"` (기록 파일만 커밋된다).
3. 사용자에게 안내한다: `/new`(또는 Codex 를 닫고 다시 `codex` → `/permissions` → `Full Access`) 후 아래 문장을 입력.
   ```
   kit.mjs board 와 WORKLOG.md 의 현재 상태, DECISIONS.md, PLAN.md 를 읽고 지금 상황을 5줄로 요약해줘. 내가 확인한 뒤 다음 할 일을 시작하자.
   ```
4. 새 세션의 요약이 맞는지 사용자가 확인한 뒤 진행한다.
