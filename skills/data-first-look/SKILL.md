# data-first-look — 데이터 첫 점검

눈으로 열어 몇 줄 보는 것으로 끝내지 않는다. 숫자로 본다.

## 순서
1. 파일 목록과 크기: `ls -la`, 줄 수 `wc -l`.
2. 표 데이터(CSV/TSV): `node .cofa/kit/scripts/profile.mjs <파일>` — 인코딩, 구분자, 열별 형식·결측·고유값·범위·상위값, 키 후보, 형식 섞임, 개인정보 의심 열.
   - 엑셀: pandas 가 있으면 `python3 -c "import pandas as pd; x=pd.read_excel('f.xlsx', sheet_name=None); print({k:v.shape for k,v in x.items()})"`, 없으면 시트별 CSV 로 바꿀 방법을 사용자와 정한다.
   - JSON/로그: 앞 5개 레코드 구조와 필드별 누락을 본다.
3. 파일이 여럿이면 **조인 키**를 확인한다: 키 값 겹침 비율, 1:1/1:N, 형식 차이(앞자리 0, 대소문자).
4. **의미 확인이 필요한 것**을 뽑아 `$interview` 질문 후보로: 결측의 의미, 이상값이 오류인지 실제인지, 단위·시간대, 코드값 뜻.
5. 요약을 `log_work` 로 남긴다(행·열 수, 주요 문제 3개).

## 보고
- 데이터 한 단락 요약(무엇을 기록한 표인가, 단위 한 행이 무엇인가)
- 문제 목록: 결측·형식 섞임·중복·이상값(열 이름과 개수)
- 처리 방침 제안(제외/대체/표시) — 결정은 사용자·담당자 답으로
- 담당자 질문 후보

## 주의
- 원본 데이터는 수정하지 않는다. 정제 결과는 새 파일이나 코드로.
- 개인정보 열은 출력·로그에 값을 그대로 찍지 않는다.
