# design — 상용 서비스처럼 정돈된 화면

화려함보다 쓰기 편한 것이 먼저다. 사용자가 원하는 답을 빨리 찾고, 값을 쉽게 비교하고, 다음 행동을 바로 알게 만든다. 색·간격·글자 값은 `ui.css` 에 고정돼 있으니, 너는 무엇을 어떤 순서로 보여 줄지만 정한다.

## 시작
1. 이 스킬 폴더의 `ui.css` 와 `fonts/` 를 앱의 정적 파일 폴더로 복사하고 모든 화면에서 불러온다. CSS 파일을 새로 만들지 않는다.
2. 부족할 때만 화면 전용 규칙을 작게 덧붙인다. 그때도 색·간격은 `var(--…)` 만 쓴다. 16진수 색, 임의 px 간격, 인라인 스타일, 다른 글꼴을 쓰지 않는다.
3. 문서 언어는 `<html lang="ko">`.

## 부품
`.app-bar` `.page` `.page.narrow` `.page-head` `.panel` `.panel-head` `.panel-body` `.stats` `.stat` `.table-wrap` `table.table` `.field` `.input` `.btn`(`.primary` `.danger` `.ghost` `.block`) `.badge`(`.ok` `.warn` `.danger` `.info`) `.alert` `.empty` `.skeleton` `.steps` `.login` `.login-box` `.ticket` `.timeline` `.grid-2` `.stack` `.row` `.muted` `.small` `.num`.

## 화면 종류별 골격
- **로그인**: `.login` 안에 서비스 이름, 한 줄 설명, 입력 2개, 버튼 1개. 소개 그림·배경 장식·기능 홍보를 넣지 않는다. 오류는 입력 바로 아래 또는 버튼 위 `.alert.danger` 로 무엇을 하면 되는지까지 쓴다. 역할은 계정으로 나누고 역할 선택 탭을 만들지 않는다.
- **운영자·관리 화면**: `.app-bar` → `.page-head`(이 화면의 일과 지금 상태, 오른쪽에 주요 행동 1개) → 진행 순서가 있으면 `.steps` → 판단에 쓰는 수치만 `.stats` → 본문 `table.table`. 표가 주인공이다. 숫자는 오른쪽 정렬·`.num`, 상태는 `.badge`, 행 행동은 `.btn.ghost`.
- **이용자·모바일 화면**: `.page.narrow` 한 칼럼. 이용자가 지금 가장 알고 싶은 답 하나를 맨 위 `.ticket` 에 크게 놓는다(예: 언제 어디서 타는가). 그 아래 경로는 `.timeline`, 부가 행동은 맨 아래. 390px 폭에서 가로 스크롤이 생기면 안 된다.
- **입력 처리**: 고르고 → 검증하고 → 적용하는 일은 `.steps` 로 현재 위치를 보이고, 다음 행동 버튼 하나만 `.primary` 로 둔다. 검증 오류는 파일·행·이유·고칠 방법을 표나 목록으로 보여 준다.

## 모든 화면에 넣을 상태
비어 있음(`.empty`: 왜 비었고 무엇을 누르면 되는지), 로딩(`.skeleton` 또는 버튼 비활성), 오류(`.alert.danger`), 성공(`.alert.ok`). 긴 이름과 많은 행에서도 깨지지 않게 한다.

## 하지 말 것
- 그라데이션, 큰 그림자, 유리 효과, 장식용 이모지·아이콘 타일, 색 띠.
- 모든 내용을 같은 카드로 나누기. `.panel` 은 실제로 묶이는 내용에만 쓴다. 수치를 카드 여러 장으로 흩지 않고 `.stats` 한 줄로 둔다.
- 화면에 강조색 버튼 여러 개. `.primary` 는 그 영역의 다음 행동 하나뿐이다.
- 「환영합니다」, 「스마트한 ○○」, 기능 설명 문단 같은 빈말. 화면에 실제 데이터와 행동을 놓는다.
- 개발 흔적(요구 ID, 내부 변수명, 영어 상태값)을 화면에 노출하기. 상태와 버튼은 한국어로 쓴다.
- 「오류가 발생했습니다」 만 쓰기. 무엇이 왜 안 됐고 다음에 무엇을 할지 쓴다. 한 화면의 말투는 하나로 맞춘다.
- 필수 요구와 검증보다 화면 다듬기를 먼저 하기.

## 끝나기 전 점검
실제 데이터로 화면을 열어 빈 데이터, 오류, 긴 글자, 390px 폭을 확인한다. 위 금지 항목을 코드에서 다시 찾아 지운다.
