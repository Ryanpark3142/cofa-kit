# next — 지금 할 일을 골라 진행 (메인 세션)

## 1. 상태 보기 (한 번)
`node .cofa/kit/scripts/kit.mjs board` — 시간·요구·다른 탭의 작업(T)·마지막 증거·커밋 안 된 변경. PLAN.md 슬라이스 표는 필요할 때만 읽는다.

## 2. 단계 고르기 (위에서부터 처음 맞는 것)
| 조건 | 할 일 |
|---|---|
| 남은 시간 ≤ 15분 | `$submit` (새 기능 금지) |
| 남은 시간 ≤ 30분이고 SUBMISSION.md 가 없거나 미완성 | `$submit` 후 `$explainback`(다른 탭 권장) |
| 등록된 요구사항이 없다 | `$kickoff` (데이터가 있으면 `$data-first-look` 도) |
| 「추론」 출처 요구나 열린 질문이 있고 담당자에게 아직 안 물었다 | `$interview` 로 질문 만들기(답을 기다리는 동안 다음 단계 진행) |
| PLAN.md 슬라이스 표가 비어 있다 | `$playbook` → `$plan` |
| 다른 탭의 작업(T)이 「완료」 인데 메인에서 다시 확인 안 했다 | `$delegate` 「돌아온 결과」 |
| 마지막 실행이 실패했거나 같은 오류가 반복된다 | `$debug` |
| 사용자가 방금 「이해 안 가」「왜?」「뭐야?」 라고 했다 | `$explain` (끝나면 원래 단계로. 길어지면 다른 탭을 권한다) |
| 경과 90분 근처이고 대화가 길고 이번 세션에 아직 안 했다 | `$handoff` 를 먼저 제안 |
| 남은 슬라이스 중 파일이 안 겹치는 것이 2개 이상이고 남은 시간 ≥ 60분 | `$delegate` 로 하나를 다른 탭에 맡기고, 메인은 `$build-slice` |
| 구현 안 된 슬라이스가 남았다 | `$build-slice` 다음 슬라이스 하나 |
| 모든 슬라이스가 구현됐고 「구현(미검증)」 요구가 있다 | `$verify` (독립 검증은 다른 탭의 `$check`) |
| 검증까지 끝났다 | `$submit` → `$explainback` |

## 3. 진행
- 고른 단계와 이유를 한 줄로 말한다: "지금은 <단계> — <이유>. <스킬> 절차로 진행합니다."
- 사용자 결정이 필요한 지점(설계안 선택, 담당자 질문 전송, 고칠 것/한계로 둘 것)에서는 멈추고 선택지를 낸다. 그 밖에는 그 스킬 절차대로 끝까지 한다.
- 끝나면 다음에 할 일 한 줄. 사용자가 다시 "다음" 이라고만 해도 이어지게.
