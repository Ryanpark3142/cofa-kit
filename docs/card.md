# cofa-kit 한 장  (다시 보기: node .cofa/kit/scripts/kit.mjs card)

## 탭 나누기 — 터미널 `+` 로 새 탭, 탭마다 `codex --yolo`
| 탭 | 맡는 일 | 첫 입력 |
|---|---|---|
| 1 메인 | 처음부터 끝까지: 파악·질문·계획·통합·제출 | `$kickoff` → 그다음은 `다음` |
| 2 작업 | 메인이 나눈 작업 하나(파일이 안 겹치는 슬라이스) | `$worker T1` |
| 3 검증·공부 | 구현을 기다리는 동안 | `$check` · `$explain <파일이나 질문>` · `$explainback` |
- 작업 탭은 메인이 `$delegate` 로 T 파일을 만든 뒤에 연다. 한 파일은 한 탭만 고친다.
- 탭은 3개까지(메모리·주의력). 지금 상태는 어느 탭에서나 `node .cofa/kit/scripts/kit.mjs board`.
- 공부·설명은 3번 탭에서 한다 → 메인 대화가 짧게 유지돼 빠르고 토큰도 덜 든다.
- 탭을 닫았으면 `codex resume` 으로 그 대화를 다시 연다.

## 메인 탭에서 내가 치는 말 (나머지는 `다음`)
- `담당자 답변: "<원문 그대로>" 반영해줘`
- `<A안>으로 간다. 이유는 <내 말 한 줄>`
- `이건 다른 탭에 맡기자` → `$delegate`
- `남은 15분. 새 기능 멈추고 $submit`

## 사람이 직접 하는 것
README 정독 · 담당자에게 질문 보내기(하나씩)·답 붙여넣기 · 설계안 고르기 · Browser 탭에서 눌러 보기 · 설명 연습 답 쓰기 · 제출 버튼

## 시간
0~15 파악·질문 │ 15~30 계획 │ 30~130 구현(작업 탭 병렬) │ 130~155 검증(검증 탭) │ 155~170 제출 문서 + 설명 연습(공부 탭) │ 170 제출

## 막히면
| 상황 | 할 일 |
|---|---|
| `codex --yolo` 가 거부됨 | `codex` → `/permissions` → Full Access |
| 스킬을 모른다고 함 | `.agents/skills/<이름>/SKILL.md 를 읽고 그대로 해줘` |
| `index.lock` 오류 | 다른 탭이 커밋 중 → 잠시 뒤 다시 |
| 응답이 느리고 대화가 김 | `$handoff` → `/new` |
| 화면·감독 오류 | 상단 「문제 신고」. 다른 창으로 나가지 않는다(규정 위반으로 기록됨) |
